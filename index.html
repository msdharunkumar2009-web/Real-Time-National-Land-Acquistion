1. Problem Statement

Land acquisition details, survey numbers, compensation and grievances are spread across many places, so landowners and officials find it hard to get information quickly.

2. Proposed Solution

The Land Acquisition Portal provides a single website to view projects, see locations on a map, record survey locations using GPS, estimate compensation and register grievances.

3. Objectives

  • Simplify the land acquisition process.
  • Show projects of all 38 districts in one place.
  • Record survey locations using GPS.
  • Estimate compensation amounts.
  • Register public grievances.
  • Save locations in the browser.

4. Technologies Used

  • HTMLWebsite structure.
  • CSSWebsite design.
  • JavaScriptInteractive features.
  • Leaflet.jsInteractive map.
  • OpenStreetMapMap tiles.
  • Browser GPSCapture current location.
  • Local StorageSave data in the browser.

This is a demo website, not an official government site. Projects, figures and the compensation estimate are samples only.
